อธิบายด้วยภาษาของตนเองว่า Workflow จะเริ่มเมื่อใด และ Job deploy ทำอะไร 
- 
- Workflow จะเริ่มทันทีเมื่อมีการ push เข้ามาใน main branch
- Job deploy ทำตามคำสั่งในไฟล์ yml

GitHub Actions แตกต่างจาก GitHub Pages อย่างไร?
- 
- Github Pages ไว้สำหรับเก็บหน้าเว็ป
- Github Actions เป็นระบบอัตโนมัติ (ไว้รันไฟล์ .yml)

ถ้าแก้ไฟล์ในเครื่องแต่ไม่ได้ push เว็บไซต์จะเปลี่ยนหรือไม่ เพราะเหตุใด?
- 
- ไม่เปลี่ยนเเปลงเพราะว่าเว็ปไซต์ทเดิมที่รันอยู่ไม่ได้มีการอัพเดท Github รันไฟล์บน Github

เหตุใดโปรเจกต์ PHP + MySQL จึงไม่สามารถนำไปรันบน GitHub Pages ได้โดยตรง?
-
- Github Pages ไม่ได้ประมวลผลอะไร เเต่ PHP ต้องการประมวลผลตลอด
- MySQL ก็ต้องการประมวลผลตลอกเหมือนกัน

อธิบายขั้นตอนการค้นหาสาเหตุ เมื่อ Workflow มีสถานะ Failed
-
- กดไปที่ Failed เเล้วเลื่อนหา error ว่าเป็น error อะไร เเละ ไปค้นหาใน google หรือไม่ก็ใช้ ai ช่วย
